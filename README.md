# Aditya’s character sheet

An 8-bit / tabletop RPG portfolio. Plain HTML, CSS and JavaScript, with no build step.

## Preview

Run `python -m http.server 8000` from this directory and open http://localhost:8000.

## GitHub Pages

This site is intended for `chymaera96/chymaera96.github.io`. In repository Settings → Pages, select **GitHub Actions** as the source. The included workflow deploys on pushes to `main`.

Edit `index.html` for content, `style.css` for design, and `script.js` for the die interaction. Keep assets in `assets/` and use relative paths so the site also works under a project URL. The Save sheet button opens the browser print dialog; select Save as PDF.

Content is based on the September 2026 CV and public project repositories. The publication marked in review retains the CV's dated status. The simplified portrait is generated from the supplied photograph. RPG ability scores and modifiers are playful character choices, independent of professional skills.

The short bio is provisional copy intended for later editing. LinkedIn and the thatsoundslike.me contribution were verified against https://uk.linkedin.com/in/adibh. Project details also use the public repositories and September 2026 CV.
